# Project provenance and usage

This portfolio develops an academic OzMart case from the University of Queensland course BISM7233. OzMart is the case organisation. This repository does not represent a commercial engagement, a production deployment, or an endorsement by the university.

The submitted report, SSIS design and historical screenshots are retained as project evidence. The case brief, source backup, reference files and source dictionary are supplied teaching materials. Their inclusion does not grant a new licence or imply ownership of the case or dataset. Check the original owner's terms before redistributing or reusing those materials. No repository-wide open-source licence is asserted over third-party course content.

The repository documentation, reconstructed SQL schema, refined analytical queries, validation scripts and synthetic demonstration were prepared with AI assistance during portfolio organisation in October 2026. These additions are identified in the [provenance register](docs/evidence/README.md). They are separate from the original assignment submission.

SSIS password elements and password verifiers have been removed, connection settings made local, and package protection changed to `DontSaveSensitive`. The original input files remain unchanged outside this repository. The archived ISPAC is a sanitised historical build, not a fresh Visual Studio build.
