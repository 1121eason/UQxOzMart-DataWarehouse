# Warehouse data dictionary

This dictionary follows the v101 SSIS destination metadata, exported as [machine-readable metadata](evidence/ssis-destination-metadata.json). Identity keys, required fields and constraints in the [SQL schema](../sql/setup/01_create_warehouse.sql) are reconstructed design choices. The separate [source dictionary](reference/source-data-dictionary.md) describes operational tables.

## DimCustomer

| Field | SQL type | Meaning |
| --- | --- | --- |
| `CustomerKEY` | int | Surrogate key generated by the target |
| `customer_id` | nvarchar(50) | Source business key |
| `Age` | nvarchar(50) | Age from the age reference, retained as text to match SSIS |
| `Education_level` | nvarchar(50) | Education description after key standardisation |
| `state_name` | nvarchar(50) | Full name of the customer's state |

The proposed diagram's optional customer names and gender are not loaded into this target.

## DimDate

| Field | SQL type | Meaning |
| --- | --- | --- |
| `DateKEY` | int | Surrogate date key |
| `Day` | int | Day of month |
| `Month` | int | Calendar month |
| `Year` | int | Calendar year |
| `FullDate` | datetime | Purchase date at midnight; one row per observed date |

## DimProduct

| Field | SQL type | Meaning |
| --- | --- | --- |
| `ProductKEY` | int | Surrogate product key |
| `product_id` | nvarchar(50) | Source product business key |
| `product_name` | nvarchar(200) | Product description name |
| `poduct_descriptions` | nvarchar(3050) | Description text; source spelling preserved |
| `product_subcategorey_id` | nvarchar(50) | Subcategory identifier; source spelling preserved |
| `Product_Category_ID` | nvarchar(50) | Category identifier from the hierarchy |
| `Product_Subcategory` | nvarchar(50) | Subcategory name |
| `Product_Category` | nvarchar(50) | Category name |

## DimSeller

| Field | SQL type | Meaning |
| --- | --- | --- |
| `SellerKEY` | int | Surrogate seller key |
| `seller_id` | nvarchar(50) | Source seller business key |
| `name` | nvarchar(50) | Seller display name; not assumed unique |
| `state` | nvarchar(50) | Short state code; explicitly `Unknown` if unresolved |
| `state_name` | nvarchar(50) | Full state name; can be null when no state-code reference matches |

## FactSales

| Field | SQL type | Meaning |
| --- | --- | --- |
| `order_item_id` | nvarchar(50) | One source order-line ID per fact row |
| `ProductKEY` | int | Link to product dimension |
| `SellerKEY` | int | Link to seller dimension |
| `CustomerKEY` | int | Link to customer dimension |
| `DateKEY` | int | Link to purchase-date dimension |
| `Revenue` | float | Source `line_total` |
| `QuantitySold` | smallint | Source `item_quantity` |

`float` and `smallint` reflect the original metadata. Fixed-precision monetary storage and a wider quantity range are reasonable future migrations, requiring corresponding SSIS metadata changes. The current warehouse has no profit, distinct-order identifier, cancellation flag or customer-acquisition denominator.
